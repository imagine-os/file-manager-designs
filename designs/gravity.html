What strength changes
Stronger ties sort earlier, sync first and appear higher in that well's ranked view.

Gravity replaces containment with attraction. Each collection is a well in a flat field, drawn as contour rings, and every file drifts toward each well that claims it. A file claimed by one well falls into it; a file claimed by two rests at the balance point between them, so the saddle between Atlas and Legal is where the shared contracts sit. Pulling a file toward a well strengthens that tie, which sorts it earlier and syncs it first. Flinging it out past the last ring breaks the tie.

How multi-home shows up
Position is membership. A file between wells is in all of them, its distance to each core is the strength of the tie, and the inspector shows those strengths as bars you can drag.
