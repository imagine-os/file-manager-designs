The sky places files by how recently and how often you open them, so the busy part is near the middle. A collection is a figure you draw between stars rather than a container you drop them into, and the Draw tool connects any star to any shape. Hovering a star lights every constellation it belongs to and dims the rest of the sky; hovering a constellation does the reverse. The inspector lists each shape the file is a vertex of, and the dashed line in the mock is a star being drawn into Archive without leaving Legal.

How multi-home shows up
A star can be a vertex in any number of constellations. Every lit shape on hover is one home, and the inspector's Constellations list is the same set with remove and add controls.
