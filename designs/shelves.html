Instead of naming a folder, you finish a sentence: everything Priya touched this week that mentions pricing. Each variable word is a chip you can swap, and saving the sentence turns it into a shelf that stays live as new files qualify. Shelves stack down the page like a bookcase, most used at the top. Files are described onto shelves rather than put there, so dropping one on a shelf it does not match asks the only sensible question: which property should change so the sentence becomes true?

How multi-home shows up
A file stands on every shelf whose sentence it satisfies, marked with a shelf-count badge and a tick between its appearances. The inspector explains each membership, and the Properties panel is where adding a value gives it another shelf.
