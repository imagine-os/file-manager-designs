Facet treats the filing scheme as a viewing angle, not a structure. The three visible faces of the cube are three groupings of the same files, by project, by client and by type, and dragging the cube brings a hidden axis around: by quarter, by person, by status. Nothing is copied or moved when you rotate. The file was always in every group it qualifies for, and the face only decides which grouping is in front. Selecting a file highlights it on every face at once.

How multi-home shows up
A file is listed under its value on every axis, so the inspector reads as one row per axis with the value beside it and a badge for which face currently shows it. Setting a value on a new axis is how you give it another home.
