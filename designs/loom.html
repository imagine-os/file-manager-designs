On this day
On Jun 18 this bead did not exist yet. It was placed 14 days later.

The loom is a timeline turned into a filing system. Each project is a thread running through the months; each file is a bead placed at the moment it was created or last changed, and the amber playhead scrubs to any day to show what was live then. Drag a bead up or down and it never leaves its thread: a dashed stitch appears and the bead now rides both, which is what is happening to hero-02.png in the mock. Threads can be hidden, bundled and reordered so the weave stays readable as the year fills in.

How multi-home shows up
A file on several threads is drawn once per thread at the same x-position, joined by a stitch. The stitch is the membership; the inspector lists each thread with the date it was strung on, and cutting one removes it there only.
