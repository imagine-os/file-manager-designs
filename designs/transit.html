The transit map is the most widely understood picture of overlapping membership, so Transit borrows it whole. Every collection is a line with its own color, every file is a station, and a file in several collections is an interchange, drawn as a larger ring where the lines meet. Pick any two stations and the map routes between them through shared collections, which turns "how are these related?" into a journey you can read off the map. Lines can be laid out by hand like a real network, or auto-routed.

How multi-home shows up
Membership count is station size. A file on one line is a small dot; a file on several is an interchange with each line arriving at it, and the inspector lists those lines with the file's position on each.
